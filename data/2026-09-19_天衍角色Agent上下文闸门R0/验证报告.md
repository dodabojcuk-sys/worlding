# 天衍角色 Agent 上下文闸门 R0 验证报告

## 结论

- 独立审查结论为 `NEED_FIX`：原 HEAD `3a2c5502252d77cf40a2e977819736263b81ee2a` 把全项目作者备注/传闻混入当前角色操作的排除计数，并把 6/12 的真实 Run 剩余预算语义写入无 Run 的预览。两项均已在本 PR 范围内修复。
- `CharacterKnowledgeHandoff.contextAccess === "character"` 是构造 `NuwaN1Context` 的前置条件；`display-only` 与 `author` 都在模型上下文构造前 fail closed。
- 角色按稳定 `objectId / observerId + revision` 绑定；显示名不参与身份匹配。
- 作者预览与 Nuwa N1 Pi Provider 工具边界复用 `projectNuwaN1ProviderSafeContext` 的安全字段投影，并通过同一稳定序列化生成逐字节相同的预览 JSON；预览对象为断开引用的快照，调用后修改内部 Context 不会污染预览。
- 预览显式标记 `previewMode`，不再向安全预览投影 `runId`、`step` 或 `remaining`。真实 Nuwa Run 的 Provider 投影仍保留这些执行字段，且误把预览投影为 Run payload 会 fail closed。
- `excluded.count` 的当前合同是“本次角色 Event 候选投影中对该角色不可见的来源数”。全项目 World Reference 中尚未进入本次候选集的作者备注/传闻不参与计数；当前林月如为 4，而不是原实现的 6。
- 预览始终为 `providerCalls=0`、`writes=0`；没有运行按钮，没有 Event、Canon、数据库、RAG 或新 Agent 框架写入。
- 被排除的作者备注、传闻、角色未知内容只保留计数与稳定原因码；标题、正文和对象名不进入模型安全序列化。
