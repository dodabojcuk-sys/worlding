# R11 UI 集成规格

状态：`REVIEWED`

## 对照结论

参考图提供了三条值得采纳的方向：选中对象以 chip 持续可见；多对象参与泳道共享事件列；视图组合明确拆为布局坐标、观察镜头和信息叠层。它不是像素稿，也不授权照搬虚构的数据语义、图标或右侧结构。

当前产品已有成熟的故事脊柱、叙事事件线、独立时间线、关系网络、详情 Dock、候选/冲突与 AI 确认流程。R11 不替换这些投影，而是在同一工具栏中把它们重新解释为“布局坐标”，并将参与和角色视角变成“主观察镜头”。

## 页面结构

```text
WorkspaceHeader（既有）
└─ EventLineWorkbench
   ├─ ObservationControlBar
   │  ├─ 布局坐标：结构 / 叙事 / 世界时间 / 关系网络
   │  ├─ 主镜头：无 / 参与 / 角色视角 / 关系演变（禁用）
   │  └─ 当前组合摘要 + 语义尺度
   ├─ 既有投影，或 ParticipationObservation
   ├─ StoryModelingToolbar（既有、作者显式启动）
   └─ PageContextDock / 既有画布 Dock
```

## 参与镜头

- 顶部显示当前组合、排序语义与证据原则。
- 左侧对象选择区读取正式 WorldObject 引用，按人物、地点、物品分组，最多五个。
- 已选对象显示为可移除 chip；删除只改变观察焦点。
- 主区按 Event 列对齐；对象各占一条泳道。
- 状态：`参与`、`见证`、`明确缺席`、`未知`。每格有文本与 `aria-label`，颜色只是辅助。
- 叙事坐标按当前 Event 投影的稳定顺序与 Story Unit 分组。
- 世界时间坐标只按可解析的正式时间排序；未知时间进入独立区，不填造日期。
- 点击事件标题或状态单元共享既有 `selectedEventId`，打开既有详情；观察组件不复制详情。
- 没有正式对象时显示可行动空态，说明需先在世界资料建立人物/地点/物品。

## 角色视角修正

- 角色视角对象列表过滤为 `type=character && formal=true`。
- 地点与物品仍可用于参与镜头，但不再进入 POV / 知情 / 误解运算。
- 既有 AI 分析入口继续要求作者显式确认；切换镜头不自动运行。

## 视觉与响应式

- 复用现有字体、颜色、间距、圆角、阴影和 lucide 图标，不引入新视觉资产或依赖。
- 1440px：对象选择区约 14rem，主泳道占余宽。
- 1152px：工具栏横向滚动；对象区约 11.5rem；主区保持可聚焦横向滚动。
- 更窄宽度：对象选择区置于主区上方，避免永久控制被裁切。
- 状态色映射现有 accent / success / warning / muted token，并同时显示文字或图形标签。

## 有意不照搬参考图

- 不复制参考图中的角色头像、世界名、单元名或事件内容；E2E 使用仓库本地 fixture。
- 不把“世界时间”默认解释成等宽事件序号。
- 不把关系网络、故事脊柱、参与、视角当作七个同级互斥页面。
- 不用地点或物品生成“信念、误解、知情”等心理状态。
- 不在参与镜头内新建事实或触发 AI。
