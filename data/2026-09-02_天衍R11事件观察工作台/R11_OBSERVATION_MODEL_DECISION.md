# R11 事件观察模型决策

状态：`APPROVED_FOR_MINIMUM_PRODUCTION_SLICE`
评审时间：2026-09-02（Asia/Shanghai）
适用入口：`apps/story-studio` 的事件工作区

## 决策

事件工作区采用“一个事实内核，多种组合式观察”的模型。一个观察状态由五个彼此正交的维度组成：

1. **布局坐标**：结构、叙事顺序、世界时间、关系网络。
2. **主观察镜头**：无、参与、角色视角、关系演变。
3. **信息叠层**：因果、时间约束、候选/冲突、来源证据。
4. **焦点对象**：正式人物、地点或物品引用；角色视角只接受正式人物。
5. **语义尺度**：故事、单元、事件。

组合必须先通过兼容性约束；不支持的组合显示原因并保持原状态，不能悄悄改写事实或制造推断。

## 十四个概念的边界

| 概念 | 权威或含义 | R11 处理 |
|---|---|---|
| 正式事实 / Owner | Canon 读取、WorldObject、Story Unit、正式 Relation 各自既有 Owner | 只读投影；不复制、不新增写入者 |
| 世界时间 | 事件发生的日期、区间、相对先后或未知 | 独立坐标；未知保持未知 |
| 叙事 / 揭示顺序 | 读者在作品中接触事件的顺序 | 独立坐标；不等同世界时间 |
| 因果拓扑 | 已确认或待评审的 Event Relation | 信息叠层或关系网络坐标；不由位置生成 |
| 参与 / 缺席 | 对象与事件的正式出现、见证、明确缺席或未知 | 本轮完整闭环；“没有标签”只能是未知 |
| POV / 知情 / 信念 / 误解 / 回望 / 观察者 | 只属于能承担心智状态的角色及有证据的陈述 | 不给地点、物品伪造心理；既有视角页作为兼容镜头，后续另行修正语义 |
| 关系类型 / 状态 | Relation Owner 的类型、方向、评审状态与版本 | 只读；关系演变镜头本轮禁用 |
| 布局坐标 | 排列同一组 Event 的视觉规则 | 纯视图状态，不是事实 |
| 主观察镜头 | 决定“正在回答什么问题”的投影 | 与布局坐标分离 |
| 信息叠层 | 可叠加、可关闭的辅助证据 | 不改变主镜头或事实 |
| 焦点对象 | 当前观察的一至五个正式对象引用 | 仅保存稳定对象 ID；缺失时降级并告知 |
| 语义尺度 | 故事 / 单元 / 事件的显示密度 | 纯本地视图状态 |
| 本地视图状态 | 布局、镜头、叠层、焦点、尺度 | URL + localStorage；不进入 Canon / World / Event |
| AI 候选 / 推断 / 冲突 / 过期 | 版本化建模结果及其状态 | 只作有来源的叠层；切换、筛选、缩放、刷新均不自动运行 Provider |

## 权威不变式

- Canon 写入者、World 事实所有者、Event 投影所有者保持唯一。
- R11 新合同只接受现有 Event 摘要、正式对象引用和既有投影结果；它不写数据库，不建第二缓存根，不新增迁移。
- 参与状态只由事件的明确标签与正式对象身份计算。正式标签包括人物/角色、地点/场所、物品/道具、目击和明确缺席。
- `unknown` 与 `explicit-absence` 是不同状态；任何缺少证据的对象—事件对都是 `unknown`。
- 视觉位置、线条相邻、筛选结果、隐藏状态和保存的组合均不能反推事实。
- AI 结果不是正式事实；必须保留来源、置信度、版本与 stale/conflict 状态，并由作者显式启动、显式评审。

## 本轮最小生产闭环

本轮实现：

- 新的组合式观察状态合同及 v1 本地持久化；
- 结构、叙事顺序、世界时间、关系网络四个现有布局的统一入口；
- “参与”镜头在叙事顺序与世界时间两种坐标上的完整闭环；
- 正式人物、地点、物品的多选焦点；
- 直接参与、见证、明确缺席、未知四态；
- 跨布局共享 Event ID、选择与焦点，点击事件继续使用既有详情 Owner；
- 兼容旧 `eventView` URL / localStorage，保存的状态缺对象时安全降级；
- 角色视角保留为正式人物专属的兼容镜头；关系演变显示为未开放，不伪装为已实现。

本轮不实现：关系演变的时间状态合同、地点/物品心理视角、自动布局引擎替换、事件事实编辑、任何自动 AI 调用、数据库迁移、依赖升级。
