# 天衍核心导航与作者便捷性整合验收

## 作者流程

普通 `/world` 首页 → 顶栏“资料” → 固定二级导航“地图” → 建图、上传底图、放置北闸、进入雾港局部图并返回 → 刷新恢复地图 → 导入《雾港设定笔记》 → 选段建立“夜间宵禁”并关联雾港、雾港守卫和林昭 → 打开地图并返回 → 打开林昭关系图并返回 → 浏览器前进/后退恢复同一资料 → 明确交给天意 → 本地假 Provider 回答 → 修改资料 → 旧回答打开原修订依据。

## 验证边界

- `attempt-5/` 是最终代码对应的完整可视证据：1440×900 地图、资料、关系、天意预览/回执/旧依据，1280×720 与 1152×720 回执状态，以及连续 WebM 录像和身份映射。
- 地图、关系与来源读写沿用 VisualDocument、Relation、World Object、Source Import 和 Document Revision History Owner；没有新建事实库。
- 流程发送 1 次本地假 Provider 请求，真实 Provider 调用 0 次；该结果证明界面与合同连续性，不代表真实模型质量或创始人人工体验验收。
- `attempt-2/` 记录第一次加入正式关系后的失败：测试错误地等待下拉选项中的隐藏文本；未归因成产品故障。`attempt-3/` 修正为等待画布上的关系标签并通过。随后门禁发现验收脚本使用禁用的 `networkidle`，已改为产品 Shell readiness；地图回归还发现新增子导航把画布推低，最终将子导航并入紧凑地图工具栏，M2 回归和 `attempt-5/` 均通过。

## 关键结论

- 旧 `/world?worldView=map|relations` 仍可读取，但顶栏归属和共享子导航都显示“资料”。
- 资料有未保存修改时，离开资料子工作区会明确确认；取消后保持当前资料。
- 地图未选地点时不渲染空检查器，作者可用“专注地图”收起全局目录。
- 《雾港设定笔记》的原始来源与 `item.*` 是同一导入来源的关联身份；列表只显示一次并解释关联，不删除 backing object。
- 名称、内容状态和可读版本优先；完整对象 ID、正文路径和修订哈希放在“技术详情”。
