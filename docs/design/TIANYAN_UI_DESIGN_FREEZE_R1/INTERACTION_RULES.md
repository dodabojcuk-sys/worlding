# INTERACTION_RULES — 天衍 UI 设计冻结 R1

## 1. 一个状态只有一个主动作
- **女娲默认态**：主动作 = “继续推演”，唯一 `.btn.is-primary`。
- **女娲有候选步骤被选中后**：主动作 = “送入待确认”；次级为“自动应用（需已授权）”。
- **世界观默认态**：主任务区首屏显示“作者下一步可以做什么”，但不把所有入口都设为主按钮。
- 任何状态下，橙色/玉色主按钮不超过一个。

## 2. 女娲紧凑走向栏
- **默认态**：高度 80–110px；显示当前推荐/已选方向 + 一句结果摘要 + 最多 2–3 个短徽标；另外两个方向只以短标签显示；提供“展开比较”动作。
- **展开态**：才显示 A/B/C 完整描述、推演依据、影响、风险、来源；使用正文下方临时比较区或轻量抽屉。
- **关闭后**必须恢复紧凑决策栏。
- **不得**遮挡 composer，不得把候选冒充正式正文。

## 3. 搜索是第二状态（世界观）
- 只有查询输入后，工作面才切换到搜索结果。
- 清空或关闭搜索后立即回到默认工作态（当前故事镜头 + 世界任务区）。
- 筛选/高级弹层不得遮挡首条结果；索引健康、检索模式、权限排除只在“检索高级”折叠内出现。

## 4. 检查器 / 抽屉规则
- **女娲检查器**：默认关闭；由角色选择、步骤右侧“角色知情”按钮或 Run 状态触发。
  - 1440：固定 320px 右栏，关闭后正文列扩展。
  - 1152：覆盖抽屉 + 遮罩，关闭后焦点返回触发按钮。
- **世界观当前故事上下文 / 对象详情**：
  - 1440：300px 右栏（当前故事上下文可常驻；对象详情按需打开）。
  - 1152：覆盖抽屉。
- **关闭方式**：Esc、遮罩点击、关闭按钮。

## 5. 候选与已确认的区分
- **已确认正文**：实线稿纸块。
- **候选步骤**：铜金虚线 + “候选 · 第 N 步 · 可采纳或放弃”标签。
- **作者秘密 / 传闻**：暗金虚线 + 锁形/问号徽标，明确排除在角色上下文之外。
- **预留功能**：虚线边框 + “预留”字样 + `disabled` 语义，不得绑定 handler 或获得焦点。

## 6. 技术信息降权
- Run ID、修订、Provider calls、token 估算、索引健康只出现在 `.tech-box` 或折叠详情内。
- 女娲场景头把运行状态缩为一个小状态点，tooltip/折叠给详情。

## 7. 响应式
| 断点 | 女娲 | 世界观 |
| --- | --- | --- |
| 1440 | 左 rail 176px + 主列 + 检查器 320px（按需） | 左 rail 176px + 主列 + 右栏 300px |
| ≤1280 / 1152 | 左 rail 收成图标 56px；检查器变覆盖抽屉 | 右栏变覆盖抽屉；任务区保持单列可读 |

- 两档均要求 `document.documentElement.scrollWidth - document.documentElement.clientWidth === 0`。

## 8. 键盘与焦点
- 全部可交互元素保留 `:focus-visible`（玉色 2px 外描边）。
- 主行动顺序：场景头 → Run 条 → 正文 → composer → 紧凑走向栏。
- 抽屉打开时焦点进入抽屉首个可聚焦项；关闭后返回触发器。
