# DESIGN_TOKENS — 天衍 UI 设计冻结 R1

方向：**温润纸张 + 玉石青绿 + 墨线结构 + 少量铜金强调**。

R1 在 R0 token 基础上保持纸张/墨线/玉青/铜金的整体方向，仅对女娲“候选/走向”与世界观“任务/因果”做了层级 token 微调。实施时映射到 `apps/story-studio/src/product-shell/theme/tokens.css` 与对应页面样式，不覆盖现有语义 token，只新增。

## 2. 墨线结构
| token | 值 | 用途 |
| --- | --- | --- |
| `--line-hair` | `#d9d2bf` | 发丝线：板块内分隔 |
| `--line-ink` | `#3a4a52` | 墨线（2px）：区域标题下划、页头下划 |
| `--line-ink-soft` | `#9aa8a4` | 中性描边 |
| `--line-candidate` | `#a0742c` | 候选虚线 |

规则：**层级优先级 = 纸色深浅 → 墨线 → 留白 → 边框圆角**。嵌套卡层最多两层。

## 3. 字体层级
| 层级 | token | 规格 |
| --- | --- | --- |
| 页面标题 | `--fs-page-title` | 1.4rem · 宋体 · 650 |
| 正文舞台 | `--fs-read` | 1rem · 宋体 · 行高 1.9 |
| 区域标题 | `--fs-region` | .95rem · 黑体 650 + 墨线下划 |
| 正文 | `--fs-body` | .85rem · 行高 1.6 |
| 辅助信息 | `--fs-aux` | .73rem |
| 状态 | `--fs-status` | .68rem |
| 技术诊断 | `--fs-tech` | .63rem · 淡色 · 折叠保留 |

## 4. 间距 / 圆角 / 阴影
- 间距：`--sp-1..6` = 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2rem。
- 圆角：4 / 7 / 10px。
- 阴影只用于覆盖层（抽屉/Dock）：`--shadow-drawer`。

## 5. 女娲 R1 辨识度
- **正文舞台**：稿纸感，宋体 1rem，行高 1.9；环境/叙述/动作/对白/心理以左缘小字标注。
- **命运织线**：场景节点用玉色/铜金圆点 + 发丝线连接；当前节点铜金光晕。
- **候选支线**：铜金虚线 + “候选 · 未编入正文”标签，不混入正文。
- **紧凑走向栏**：默认 `--paper-deep` 底，高度 80–110px，与正文区分。

## 6. 世界观 R1 辨识度
- **当前故事镜头**：铜金边框 + 当前场景锚点，回答“当前场景用到了哪些世界事实”。
- **世界任务区**：纸色略深，动作列表为首，而不是展示卡堆。
- **因果视图**：只在规则/制度/系统对象下按需展开，墨线 + 语义色描边，无证据不画线。
- **演化轨迹**：实心=已确认、虚线=不确定、暗金=作者秘密、铜金光环=当前故事位置。
