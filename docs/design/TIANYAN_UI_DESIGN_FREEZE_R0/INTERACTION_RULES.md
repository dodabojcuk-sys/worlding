# INTERACTION_RULES — 天衍 UI 设计冻结 R0

## 1. 一个屏只有一个主任务
- 女娲：主任务 = 阅读/编辑本场戏；唯一最高优先级按钮 = 「继续推演」。
- 世界观：主任务 = 看懂世界当前状态；页头动作均为次级。
- 每个状态只允许一个 `.btn.is-primary`；其余为次级/文字级。

## 2. 搜索是第二状态（世界观）
- 只有输入查询后才切换到搜索工作面；离开输入即回到总览。
- 筛选/高级弹层不得遮挡首条结果；索引健康、检索模式、权限排除只在「检索高级」折叠内出现。

## 3. 检查器 / 抽屉按需出现
- 女娲检查器默认关闭，由角色/步骤选择或「角色知情」按钮打开；1440 为 320px 右栏（不挤压正文列宽），1152 为覆盖抽屉 + 遮罩。
- 世界故事上下文：1440 常驻右栏；1152 覆盖抽屉。
- 关闭方式：Esc / 遮罩点击 / 关闭按钮；关闭后焦点返回触发按钮（原型已实现遮罩与按钮，键盘 Esc 在实施时随生产抽屉合同执行）。

## 4. 候选与已确认的区分（女娲）
- 已确认正文：正常稿纸块；候选：铜金虚线支线 + 「候选 · 第 N 步」标签 + 织线提示「尚未编入正文」。
- 候选走向 A/B/C 为选择卡，选中态用玉色描边；选择后动作仍走既有「送入待确认 / 自动应用」链，不新增写入行为。

## 5. 状态表达：文字 + 形状，不只靠颜色
- 已确认=实心玉点；不确定=虚线空心；作者秘密=暗金虚线 + 🔒；当前故事位置=铜金光环点；规划/候选空态=虚线框诚实文字。
- 设计预留一律虚线边框 + 「预留」字样 + 不可聚焦为假动作（`disabled` 语义，实施时不得绑定任何 handler）。

## 6. 技术信息降权
- Run ID、修订、Provider calls、token 估算、索引健康只出现在 `.tech-box`（.63rem 淡色 + 虚线）或折叠内；不进入标题区、不与作者正文混排。
- Provider/运行状态在女娲场景头缩为一个状态点（tooltip/折叠给详情）。

## 7. 响应式（真响应式，非等比缩放）
| 断点 | 女娲 | 世界观 |
| --- | --- | --- |
| 1440 | 轨道 176px + 主列（正文舞台 ≤740px）+ 检查器 320px（按需） | 右栏 300px 常驻；脉搏 4 块横排 |
| ≤1280 | 轨道收成图标 56px；检查器变覆盖抽屉；正文 ≤680px 仍可读 | 脉搏 2×2；演化双列变单列；故事上下文变抽屉 |
- 两档均要求 `documentElement.scrollWidth - clientWidth === 0`（原型实测均为 0）。

## 8. 键盘与焦点
- 全部可交互元素保留 `:focus-visible`（玉色 2px 外描边）。
- 主行动顺序：场景头 → Run 条 → 正文 → composer；抽屉打开时焦点进入抽屉，关闭后返回触发器。
