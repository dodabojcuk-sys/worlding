# DESIGN_TOKENS — 天衍 UI 设计冻结 R0

方向：**温润纸张 + 玉石青绿 + 墨线结构 + 少量铜金强调**。
专业创作软件，有中国叙事工具气质但不做古风网页；不做宣传册、不做霓虹科幻、不做满屏渐变、不给所有模块套同一种白色圆角卡。
原型实现见 `design-prototypes/tianyan-ui-freeze-r0/proto.css`；本文件是唯一 token 定义稿，实施时映射到 `product-shell/theme/tokens.css`（不覆盖现有语义 token，只新增）。

## 2. 墨线结构
| token | 值 | 用途 |
| --- | --- | --- |
| `--line-hair` | `#d9d2bf` | 发丝线：板块内分隔 |
| `--line-ink` | `#3a4a52` | 墨线（2px）：区域标题下划、页头下划——层级的主承担者 |
| `--line-ink-soft` | `#9aa8a4` | 中性描边 |

规则：**层级优先级 = 纸色深浅 → 墨线 → 留白 → 最后才是边框圆角**。嵌套卡层最多两层（板块 + 内部行）。

## 3. 字体层级
| 层级 | token | 规格 |
| --- | --- | --- |
| 页面标题 | `--fs-page-title` | 1.4rem · 宋体（`--font-read`）· 650 |
| 正文舞台（女娲稿子） | `--fs-read` | 1rem · 宋体 · 行高 1.9 |
| 区域标题 | `--fs-region` | .95rem · 黑体 650 + 墨线下划 |
| 正文 | `--fs-body` | .85rem · 行高 1.6 |
| 辅助信息 | `--fs-aux` | .73rem |
| 状态 | `--fs-status` | .68rem |
| 技术诊断 | `--fs-tech` | .63rem + 淡色 + 虚线框，折叠保留；**禁止与作者内容同权重** |

## 4. 间距 / 圆角 / 阴影
- 间距：`--sp-1..6` = 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2rem。
- 圆角克制：4 / 7 / 10px。
- 阴影只用于覆盖层（抽屉/Dock）：`--shadow-drawer`；页面内层级不用阴影。

## 5. 女娲 / 世界观各自辨识度
- **女娲**：命运轨迹细线（场景节点用 `--jade`/`--copper` 圆点 + 发丝线相连）、候选步骤为铜金虚线支线（未编入正文）、正文舞台宋体稿纸感。
- **世界观**：语义色徽标系统、因果网络节点连线（墨线+语义色描边）、演化轨迹多态标记（实心=已确认、虚线=不确定、暗金=作者秘密、铜金光环=当前故事位置）。
