# 天衍界面设计约束

> 本文记录已实现 Shell 的可验证约束，不是替代产品核心的视觉提案。视觉/体验仍需作者独立验收。

## 布局与焦点

- 八空间是稳定一级导航；工程目录是项目范围的二级导航；中央工作面始终保留路由内状态。
- 目录的打开意图按项目保存。窄屏、详情和天意等临时工作面只能暂停呈现，关闭后恢复路径、选择、滚动和焦点。
- 同一时刻只有一个右侧 ContextDock 工具。空间不足时目录与 Dock 互斥，隐藏栏不得继续占宽或遮挡 composer/末项操作。
- `/tianyi` 的创意/工作与页面天意 Agent 分别表达会话泳道和 Page-scoped Run；不靠同名标签暗示它们是不同事实 Owner。

## 密度与组件

- 使用既有语义 token（字体、间距、边框、圆角、状态色）；避免无业务含义的渐变、阴影和大面积空卡。
- 阅读面优先正文、候选、影响和下一步；技术 ID、版本、运行细节在可展开诊断中保留。
- 一个状态只突出一个主要动作。候选、已确认、冲突、未知、过期与派生状态必须同时使用文字和非颜色线索。
- 列表、目录和画布以稳定 ID 引用对象；选择、筛选和布局不复制 Event、Relation、Canon 或正文。

## 响应式、键盘与错误

- Shell 变更至少人工核对 1440、1195、1152 和 1024：首屏输入、目录/Dock 互斥、无 body 横向溢出、可见末项动作、Esc 和焦点返回。
- 画布保持缩放、平移、适应/定位当前等统一语法；未知时间、冲突和候选必须以诚实状态呈现。
- 加载/错误提示说明数据是否安全以及下一步；内部诊断可展开，不能把运行 ID 或 Provider 细节作为普通作者界面的主文案。
- 自动测试与截图只证明指定状态，不能取代真实模型或作者体验验收。

## 异步只读投影

- 工程目录的加载态、合法空态、失败态必须分开；没有完成的读取不能显示成 0，合法空项目也不能靠通用长退避伪装成“正在恢复”。
- Story Unit Owner 明确绑定的正式 Event 成员和集点应随核心目录读立即呈现；Canon verified-ID 异步读用于补充未被 Unit 声明的事件，不能让作者先进入一个暂时空的单元。
- 同一项目、同一相对 URL 的并发只读投影合并在途 Promise，并允许 5 秒内重复挂载复用刚完成的快照；任何写请求立即失效，时窗结束、失败或超时也必须释放，不能变成跨版本缓存或第二数据 Owner。
- 诊断只记录项目/版本引用、阶段、数量、状态码、耗时和丢弃原因。正文、请求体、Authorization、Cookie、密钥与附件不进入浏览器 trace。
- 1195 与 1440 的目录验收不仅看条目出现：还要确认中央工作面未被遮挡、角色观察条高度不随目录路径变化、Creative/Work composer 可见可达且页面无横向溢出。

## 事件线收尾

- 顶部只保留当前任务必需的频繁操作；当前范围、焦点、时间核对、证据审计、故事结构和关系网络收入固定可见的“更多”菜单。
- 人物选择的唯一入口位于角色观察区；选中后以 `n/5 人` 保持同一入口，不在顶栏复制。
- “更多”菜单使用正式 menu/menuitem 语义，Esc 关闭后焦点回到触发器。1195 同时打开详情检查器时仍保留右侧工具栏，并且 body 无横向溢出。

## 已接通的女娲 N1 本地工程面

- 从当前作品按稳定 ID 选 2 个正式角色和 1 个场景；一次 Run 最多 6 个已提交步、12 次调度，非活动角色不请求执行器。
- 角色上下文在实际请求边界按身份、分支、时点和可见性过滤；身份摘要不等于知识，其他角色的秘密、内心和作者未来意图默认排除。
- 产品路径支持暂停、恢复、停止和回放；选定结果只进入既有待确认/影响/Owner 链，不直接写事实。
- 1440 使用中央连续阅读与右侧上下文检查器的明确双栏；1195 将检查器转入文档流。两档都保留 Shell 右工具栏，sticky 作者提示与“送入待确认”不得被遮挡。
- 工程假执行器必须显示“本地工程演练 · 0 Provider”；未配置时明示不可执行，不以固定台词冒充真实对话。

## 已规划：地图 M1

- 地图继续使用世界空间、同一个右侧检查器和既有地点/Relation/Event 身份；地图布局只记录示意坐标与视口，不表达控制、所有权、现居、通行或世界时间事实。
- 默认先显示地点；势力、人物与事件关联在选择或筛选后展开，并逐项显示关系类型、方向、状态和来源。“曾被目击”不得自动解释为“当前居住”。
- 1195 与 1440 都以地图为主区；目录或检查器使画布不足时按 Shell 互斥规则切换，不增加并排右栏或自动反复全图适配。
