# 世界构建与资料工作区 M1

资料工作区直接读取和编辑既有 World Object：正文、稳定对象 ID、版本哈希、归档和冲突仍由现有 World Owner 负责。地图只使用 VisualDocument 保存底图与地点布局；地点、区域、关系和故事状态不因移动标记而被推断或改写。关系继续经 Relation Owner，天意只接收作者明确选择且经既有 Grounded Context Gate 校验的资料版本。

## 现状与本轮边界

### 已经可用

- 资料页直接读写现有 World Object，支持正文、标签、状态、版本与归档。
- 地图和关系分别沿用 VisualDocument 与 Relation Owner；资料页只提供入口，不复制事实。
- 天意已有明确资料选择、发送前重验、Grounded Context Gate 与冻结回答回执。

### 已有但曾断开

- Source Import 已能逐字保存原始材料和行／字符锚点，但普通资料工作区不能导入、阅读或从选段建立设定。
- 文档历史已有快照，前端投影却缺少 `contentHash`，因此回答冻结哈希无法安全定位到旧正文。
- 资料对象能写 Markdown 关联，但缺少稳定对象引用、失效提示和地图／关系／天意的连续返回状态。

### 本里程碑已补齐

- 资料工作区可粘贴或导入 Markdown／TXT，逐字保留原文；可选段建立未确认规则草稿，并保留来源文档、行号和来源修订。
- 世界设定可自由写作并选填“规则内容／适用范围／例外”，明确区分草稿和作者确认；导入和编辑均不制造 Event，也不扩散为角色知识。
- 资料搜索覆盖标题、标签和别名，原始来源另可搜索标题、文件名与原文；支持类型、状态、最近编辑筛选。对象关联采用稳定路径，改名后仍可定位；缺失引用不以同名对象代替。
- 从资料打开地图、关系或天意后可返回原条目与筛选上下文。天意预览显示正文与修订，回答回执显示实际采用的资料；资料后来修改时，旧回答按原 `contentHash` 打开历史正文，拒绝以当前正文冒充旧依据。

OCR、网页抓取、大批量解析、自动合并同名对象和新的记忆引擎不在 M1 范围。
