# 天衍可视化世界演进方案 R0（产品建议稿）

状态：设计建议，未冻结需求。依据任务书 TIANYAN_R2A §7-§8 整理；实现前需创始人确认 §6 的开放问题。不改八空间、不新增顶级导航、不建第二事实库。

## 1. 用户原意（整理，非锁定）

用户提出五个方向并明确它们是"同一故事世界的不同观察方式"：地图（在哪里）、人物圈层（谁与谁有哪些联系）、势力（组织如何相互作用）、宗族（亲缘与代际）、时间/剧情关键帧（什么时候/哪一章变成这样）。并强调"先画、先摆、先构思，再逐步整理"——不应为画一条道路先填一整套表单。

## 2. 已有能力（以 项目目录导航.md 与代码为准，逐项核对成熟度）

- VisualDocument：图层、连续山林笔触、形状/文字、撤销/重做、修订保护、保存冲突恢复。
- 局部地图：子图多父 placement、世界→地区→城市逐层进入、坐标校准、跨图连接。
- 地图提案审阅：mapEditProposalRepository（待审操作、基准修订、决定回执）。
- 关系：Relation Owner（候选→作者确认）、关系图阅读器、人物聚焦。
- 事件线：叙事编排权威、时间投影、证据审计。
- WorldState：观察位置由已确认事件派生。

结论：不新写地图系统；本方案是把既有底层变成顺手的工作台。

## 3. 三个"层级"概念分开

| 维度 | 含义 | 不得混淆 |
| --- | --- | --- |
| 绘图图层 | 底图/地貌/水系/聚落/道路/边界/标注的叠放 | 图层顺序≠故事地位 |
| 地理尺度 | 世界→大陆→地区→城市→建筑内部（局部地图） | 空间包含关系，非叠放顺序 |
| 缩放细节 | 缩远看大陆，放大看村庄道路 | 显示密度，不复制地点数据 |

## 4. 地图工作台第一阶段（"好画、好选、好改、好返回"）

1. 稳定平移/缩放、选择/多选/框选、对象信息查看；解决地块遮挡命中问题。
2. 画笔预设（山/林/沙/雪）、海岸/河流/道路线形编辑、样式预设；减少"填表画图"。
3. 图层顺序、锁定/隐藏清楚可见。
4. 局部地图进入/返回保持视口；未校准比例时只显示"局部地图"。
5. 语义缩放：按缩放密度显示/隐藏标注。

先画后结构化：道路先是一条线；城镇图示先只是构思。作者明确执行"关联地点/定义领地"时才进入故事结构（走既有 owner，保留回执与撤销）；纯视觉编辑不改事实。

## 5. 圈层/势力/宗族（关系阅读的三个投影）

- 人物圈层：圈层可重叠，一人可属多个圈。自由视觉分组（仅视图）与正式成员关系（明确动作走 Relation owner）必须可区分；多重归属用徽标/清单/聚焦辅助，不为画圆改数据、不复制人物。
- 势力：组织为对象块，连线带类型/方向/有效时期；"供资源"与"依赖保护"是两条有向关系，不合并成含糊双向。无连线=未展示/未定义，不推定中立。可展开组织成员并进入同一人的关系资料。
- 宗族：代际/支系折叠阅读；婚姻/收养/继承/任职不一律当父子边；同一人物跨支系引用同一身份。血缘视图与家族-势力视图可切换。

## 6. 时间/剧情关键帧

- 三种时间分开：世界时间、剧情揭示位置、编辑修订时间（沿用既有 owner，不建第四套事实）。
- 观察：选择事件或世界时间作为命名锚点，查看当时的地图/关系/人物状态；记录视图选择与来源版本绑定。
- 规划：未来帧明确标注为计划/候选，交给天意讨论实现路径，不自动改写前后事件。
- 不得动画插值编造中间状态；无历史几何时明示缺失，不用当前地图冒充历史地图。
- 第一切片：一张地图 + 两个已确认观察时点 + 少量关系变化 + 一个规划帧 + 切换/回溯保持。

## 7. 明确不做（本轮）

不做完整文明演化模拟、不做地形物理引擎、不照搬 Figma/Azgaar 的数据结构、不新增顶级空间、不动八空间布局。地形计算（抬高/侵蚀/水系检查）需要高程与规则数据，单独立项。

## 8. 正常用户验收脚本（首切片后）

1. 从资料进入地图，画笔预设画出山脉/森林/河流/道路/城镇图示，全程无需填表。
2. 图层锁定/隐藏/排序；遮挡对象可被选中。
3. 双击城镇图示进入局部地图，返回后视口保持。
4. 把城镇图示"关联到已有地点"，出现回执，可撤销。
5. 两个命名观察时点切换，关系变化与事件对应；规划帧保持为候选。
6. 刷新重开后以上状态保持。

## 9. 已确认与开放问题

**创始人已确认（2026-09-16）**：图一中不同颜色代表不同阵营的范围；范围可以重叠；同一个人可以同时属于多个阵营。界面必须同时表达多重归属，不得迫使作者选择单一"主要阵营"。阵营颜色只区分阵营身份，不表达确认状态/敌我/领土；候选、正式等状态另用标签与线型；阵营必须有名称或图例（W3C 1.4.1）。

关闭的问题：图一颜色含义（已确认）、"织网app"归因（仅影响竞品研究，不影响施工）、首切片地图与时点（执行端在独立合成作品中自行选择，无历史依据的子项如实标注）。

仍开放（实现建议，非冻结）：区域轮廓算法、颜色数量与透明度、徽标形状、首个示例对象、两时点对照排版。
